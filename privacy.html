Privacy Policy

Effective 21 October 2026

Purpose and scope

Joint Monzo Automations is a private, personal-use application operated solely for its owner's household finances. It is not available as a public service.

Google data accessed

The application requests the Gmail read-only scope. It searches the owner's mailbox for authenticated Amazon order, dispatch, cancellation, return, and refund emails near the date of a corresponding Monzo transaction. It reads message metadata and content needed to identify the order, amount, item description, and an optional Amazon-hosted product image.

How data is used

Google user data is used only to match Amazon emails with the owner's Monzo transactions. A successful match may add a derived item description and product image to that Monzo transaction. Gmail access is not used for advertising, profiling, credit decisions, or any unrelated purpose.

Storage and retention

Raw email bodies and unrelated mailbox content are not persisted. The application stores limited processing state, such as a transaction identifier, match status, timestamps, a non-reversible event fingerprint, and the derived transaction note. This state is retained only for operating and troubleshooting the owner's automation and may be deleted by the owner at any time.

Sharing and disclosure

Google user data is not sold, rented, transferred, or shared with third parties. Derived transaction notes and optional product images are sent only to the owner's Monzo account as part of the requested automation. Infrastructure providers process data only as required to run the application.

Security

OAuth credentials are stored as encrypted secrets. Access is limited to the application's runtime identity and the owner. The application requests the minimum Gmail permission required and cannot send, modify, or delete email.

Revoking access and deletion

The owner can revoke the application's Google access at any time from the Google Account security settings. The owner can also request or perform deletion of the application's stored processing state and credentials.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
