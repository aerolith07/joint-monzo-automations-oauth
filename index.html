Personal-use automation

Joint Monzo Automations

A private tool used by its owner to reconcile a joint Monzo account, keep transaction records up to date, and add useful item descriptions to Amazon transactions.

Why it accesses Gmail

The tool requests read-only Gmail access so it can locate genuine Amazon order and refund emails that correspond to the owner's Monzo transactions. It uses those matches to add an item description and, when available, an Amazon product image to the related Monzo transaction.

  • Access is read-only: the tool cannot send, modify, or delete email.
  • It is not offered to the public and has no advertising or analytics.
  • Google user data is not sold or shared with third parties.
